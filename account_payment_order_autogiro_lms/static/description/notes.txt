IB-45 (2026-09-28): the module icon shows the HERITAGE the module builds on,
not its function. All modules in this repo inherit from the Odoo core module
'account' and therefore share the same heritage symbol.
IB-26 (unique symbol per module) is superseded.

Diagrams in static/src/img/ are generated by matplotlib (Vertel palette),
not Inkscape. See the module's git history for the generator.

Guide:
1. Use Inkscape to create a colored background. (Import)
2. Odoo icon: 140 x 140, 560 x 280.
3. Pick icon at fontawesome and paste in a text field.
4. Save in ordinary / plain svg format.
5. In Inkscape, choose Generate PNG image and "Export as...".
6. Write a filename...
7. Be careful when selecting the filename! It's easy to select the wrong path!
8. ...of choice and choose "Export".
