Mynt

Mynt is a complete solution for company expenses, with company cards linked to accounting. Mynt is based in Sweden and is today used by thousands of companies.

Using a module developed by Vertel there is now an integration between Odoo and Mynt, making accounting easier and more effective.

Mynt och Odoo

How does the integration between Odoo and Mynt work?

Go to the Accounting and Export function in Mynt. The integration enables an easy transfer of economic information, including receipt images, to enter the accounting in Odoo.
